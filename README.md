# Swiggy-Data-Analysis-Dashboard

## Project Overview
This project is an interactive Swiggy Data Analysis Dashboard created using Tableau. The dashboard provides insights into revenue, customer ratings, delivery time, payment methods, and hourly order trends.

---

## Tools Used
- Tableau Public
- Microsoft Excel
- Data Cleaning
- Data Visualization

---

## Key KPIs
- Total Revenue: 812,216,126
- Total Orders: 1,048,575
- Average Delivery Time: 37.47
- Average Rating: 3.0

---

## Dashboard Features
- Customer Rating Distribution
- Revenue by Income Group
- Orders by Hour
- Orders by Payment Method
- KPI Cards
- Interactive Dashboard Visualizations
